Tu libro: portfolio y certificados

Los borradores son privados. Marca “Publicado” para mostrar una entrada en las páginas públicas.

profile · Perfil y portada

Una sola entrada. Título = nombre (portada) · Resumen = titular · Categoría = “ahora mismo” (p. ej. Open to remote pentesting roles) · Emisor = ciudad · Descripción = bio · Competencias = skills · Web = LinkedIn · Repositorio = GitHub · Verificación = enlace para reservar llamada · Portada = tu foto · Documento = CV en PDF.

experience · Dónde he trabajado

Una entrada por puesto. Título = puesto · Emisor = empresa · Inicio y fin (fin vacío = “since 2024”) · Categoría = ciudad o modalidad · Descripción = logros · Competencias = herramientas. Orden 0 = arriba.

education · Dónde he estudiado

Título = titulación (p. ej. BSc Cybersecurity & Networks) · Emisor = universidad · Inicio y fin · Descripción = módulos o proyecto final.

project · Portafolio

Título · Resumen · Categoría (crea las pestañas) · Descripción (línea en blanco entre párrafos; “# Título” crea subtítulo) · Competencias = tecnologías · Emisor = rol/cliente · Fecha · Web · Repositorio · Verificación = caso práctico · Portada + Galería · Documento = informe PDF. Identificador = enlace directo /portfolio/#identificador.

certificate · Certificados

Título · Emisor · Expedición y caducidad (opcional; avisa “Renew soon” 90 días antes) · Resumen = ID de credencial · Categoría (pestañas) · Verificación = URL oficial · Portada = imagen · Documento = PDF.

link · Redes y email

Una entrada por red: Título = nombre (GitHub, TryHackMe…) · Web = URL https (el icono se pone solo). Para el email: Título = Email · Resumen = tu dirección; activa la carta de contacto.
